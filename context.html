05 · FAQ

Questions,
answered.

Still curious? Our docs go deeper — or start free at app.context.veeliq.com.

What is Context? +

Context is a private knowledge and memory layer for the AI you already use. Upload documents and your agent answers from them; ask it to remember something and it recalls it next session, in any MCP client. It is live in Beta with a free plan.

Do I need an API key or AI model? +

No. Context rides on top of the AI you already use — Claude, Cursor, ChatGPT. You never provide a model key. We only act as a tool provider over MCP.

Which clients are supported? +

Any MCP-compatible client. That includes Claude.ai, Cursor, ChatGPT, Zed, Windsurf, and growing. One URL covers all of them.

What happens with my data? +

Your documents and memories live in your own isolated space, enforced with row level security. We never train models on your content, and deleting a source or memory removes it from retrieval immediately.

What are the free plan limits? +

The Beta free plan includes document uploads, knowledge search, and memory under fair usage limits. Current limits are always listed in the dashboard at app.context.veeliq.com.

How does Context relate to the Skills Marketplace? +

Same platform, same one-URL philosophy. Context gives your AI private knowledge and memory today; the Skills Marketplace adds expert skills next. Context subscribers will see it first.
